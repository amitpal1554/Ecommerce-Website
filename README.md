# 🛒 E-Commerce Website

## 📌 Description

This is a fully functional e-commerce website where users can browse products, add to cart, and place orders.

## ✨ Features

* Product listing page
* Add to cart
* Remove from cart
* Responsive design
* User-friendly UI

## 🛠 Tech Stack

* HTML, CSS, JavaScript
* React 
* Node.js, Express.js 

## ▶️ How to Run

1. Clone the repository
2. Open project in VS Code
3. Run the project
